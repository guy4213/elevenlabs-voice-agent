# סוכן קולי עם ElevenLabs Agents: דמו

סוכן קולי בעברית ודשבורד מקומי לשיחה איתו. מדברים, וכשמסיימים לדבר הסוכן עונה מיד.

**להעתקה לפרויקט אחר:** ראו [INTEGRATION.md](INTEGRATION.md). יש בו endpoint לשרת, קומפוננטת React ו-JS רגיל, וגם את מה שלמדנו על עברית.

## התקנה ראשונה

```bash
cp .env.example .env   # ולהכניס את ELEVENLABS_API_KEY
```

## הרצה

```bash
npm run agent   # יוצר את הסוכן ב-ElevenLabs (או מעדכן אותו אם כבר קיים)
npm start       # מריץ את הדשבורד בכתובת http://localhost:3000
```

בפעם הראשונה הדפדפן יבקש הרשאה למיקרופון. צריך Node 20.6 ומעלה, ולא צריך להתקין שום חבילה.

## טסטים

כש-`npm start` רץ בטרמינל אחר:

```bash
npm test               # שרת + שיחה קולית אמיתית: שאלה מוקלטת בעברית נשלחת לסוכן, ונבדקים התמלול, התשובה וזמן התגובה
npm run test:browser   # הדשבורד עצמו ב-Chrome headless, עם מיקרופון מזויף שאומר את השאלה
```

כל הרצה היא שיחה קצרה אחת מול ElevenLabs, ולכן צורכת מעט קרדיטים.

## כשמשהו לא עובד

- **הסוכן לא שומע אותי:** בוחרים בדשבורד את המיקרופון הנכון ובודקים שהפס "אתה" זז כשמדברים.
  אם אחרי 8 שניות לא מגיע קול מהמיקרופון, תופיע אזהרה.
- **"הגעת למגבלת השיחות במקביל":** בחשבון החינמי מותרות רק כמה שיחות במקביל. מחכים דקה-שתיים.
- **שגיאת רשת:** השרת מנסה כל בקשה עד 3 פעמים ורושם בטרמינל את הסיבה המדויקת.

## מבנה

| קובץ | מה הוא עושה |
| --- | --- |
| `.env` | מפתח ה-API ומזהה הסוכן. **לא להעלות לגיט** (הוא כבר ב-`.gitignore`) |
| `scripts/create-agent.mjs` | ההגדרות של הסוכן (פרומפט, שפה, קול, מהירות תגובה), שנשלחות ל-API |
| `server.mjs` | שרת מקומי שמגיש את הדשבורד ומנפיק קישור חתום (signed URL) לכל שיחה. המפתח נשאר בשרת |
| `public/` | הדשבורד: עיגול מיקרופון, בחירת מיקרופון, תמלול חי, זמני תגובה והגדרות הסוכן |
| `scripts/test.mjs`, `scripts/test-browser.mjs` | הטסטים |

## לשנות את הסוכן

עורכים את האובייקט `agent` בקובץ `scripts/create-agent.mjs`, למשל את הפרומפט, הודעת הפתיחה או `voice_id`,
ומריצים שוב `npm run agent`. הסוכן הקיים מתעדכן, וה-ID שלו לא משתנה.

אפשר לערוך את הסוכן גם בממשק של ElevenLabs. שני הצדדים עובדים על אותו סוכן, אבל הרצה של `npm run agent`
דורסת את השדות שמוגדרים בסקריפט.

## איך זה עובד

1. הדפדפן מבקש מהשרת המקומי `/api/signed-url`.
2. השרת מבקש מ-ElevenLabs קישור חתום לשיחה עם המפתח הסודי, ומחזיר רק את הקישור.
3. הדפדפן פותח שיחה דרך WebSocket עם הסוכן, עם `@elevenlabs/client`.
   בחרתי ב-WebSocket ולא ב-WebRTC, כי טוקן WebRTC תופס מקום במכסת השיחות במקביל כבר כשמנפיקים אותו,
   ובחשבון החינמי המכסה מתמלאת אחרי 5 ניסיונות.
4. ElevenLabs מזהים מתי סיימת לדבר (`turn_eagerness: "normal"`), והסוכן עונה תוך כשנייה. אפשר גם לקטוע אותו באמצע.
   עם `eager` הוא קטע אותך כבר בהפסקה קצרה (למשל באמצע "אני רוצה-").

על הסוכן מופעל auth, כך שמי שמחזיק רק את מזהה הסוכן לא יכול לפתוח איתו שיחה ולבזבז קרדיטים.
